# GDSync — Google Drive オンデマンド同期（Obsidianプラグイン）

[English README](README.md)

モバイル（iOS/Android）の Obsidian から Google Drive 上の Vault データを**オンデマンド**で読み書きするプラグインです。

- Drive のフォルダ/ファイル構造を Vault 内の `GDrive/`（変更可）に **0バイトのスタブ**として再現 → Obsidian 標準のファイルエクスプローラー/クイックスイッチャーがそのまま使える
- ファイルを**開いた時**に Drive から実体をダウンロード（ハイドレート）
- **編集すると自動アップロード**（デバウンス数秒、チェックサムによる競合検出 → 競合時は `(conflict …)` コピーを作成）
- 一度開いたファイルはローカルにキャッシュ。古いキャッシュは自動でスタブに戻る
- 作成 / リネーム / 削除も Drive に反映（削除は Drive のゴミ箱へ。完全削除はしない）
- PC 側は Google Drive for Desktop で同じフォルダを Vault にすれば OK（このプラグインは既定でモバイルのみ動作）

## 他の同期プラグインとの違い

既存のコミュニティプラグイン（*Google Drive Sync*、*Remotely Save* など）はリモート Vault 全体をローカルに複製します。GDSync は軽量なスタブツリーだけを保持し、内容を遅延取得するため、ストレージの少ないスマートフォンで大容量 Vault（数GBのPDF・画像など）を扱うのに向いています。「完全レプリカ」ではなく「オンデマンドキャッシュ」です。

## 必要要件・通信・プライバシーについて

- **アカウント:** Google アカウントと、**自分専用**の Google Cloud OAuth クライアント（無料）が必要です。プラグインには開発者の認証情報は同梱されていません。
- **通信先:** `accounts.google.com` / `oauth2.googleapis.com` / `www.googleapis.com`（Drive API）のみ。第三者サーバーへの送信・テレメトリはありません。
- **スコープ:** フル `https://www.googleapis.com/auth/drive` スコープを要求します。Drive for Desktop 等の他アプリが作成したファイルを読むため、`drive.file` では不十分です。自分専用の OAuth クライアントなので、他人のアカウントからは利用できません。
- **全 Drive のメタデータ取得:** ミラーインデックス構築のため、マイドライブ全体のファイル*メタデータ*（名前・ID・チェックサム）を取得します。ファイルの*内容*は、選択したフォルダ内で開いたものだけをダウンロードします。
- **認証情報の保存:** クライアントID/シークレットとトークンは Vault 内の `data.json` に**平文で**保存されます（多くの同期プラグインと同様）。`.obsidian` フォルダを共有しないでください。専用の Google Cloud プロジェクトの利用を推奨します。
- **クリップボード:** 「Copy code」で接続コードをコピーする時に1回だけ書き込みます。読み取りは一切しません。接続コードはトークンを含むため**パスワードと同等に**扱い、転送に使ったメッセージ等は使用後に削除してください。
- **ローカルポート:** デスクトップでのサインイン中のみ `127.0.0.1:42813`（ループバック限定、外部非公開）で OAuth リダイレクトを待ち受け、完了後すぐ閉じます。

## セットアップ

### 1. Google Cloud プロジェクト（自分専用）

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクト作成
2. 「APIとサービス」→「ライブラリ」→ **Google Drive API を有効化**
3. 「OAuth 同意画面」: User Type = **外部**、スコープに `https://www.googleapis.com/auth/drive` を追加
4. 公開ステータスを **「本番」に移行**（テストのままだとリフレッシュトークンが7日で失効する）。未検証アプリ警告は自分のアカウントなら「詳細」→「（安全でないページに）移動」で通過できる
5. 「認証情報」→ OAuth クライアントID作成 → 種類 = **デスクトップアプリ**。クライアントIDとシークレットを控える。**リダイレクトURIの登録は不要**

外部セットアップはこれだけです — ページのデプロイもサーバーも不要になりました。

<details>
<summary>代替手段: モバイル単体でブラウザ認証する場合（リダイレクトページ）</summary>

デスクトップを持たない場合は、OAuth クライアントを**ウェブアプリケーション**型で作成し、`redirect-page/index.html` を静的ホスティング（GitHub Pages / Cloudflare Pages 等）にデプロイして、そのURLを承認済みリダイレクトURIに登録します。ページは認可コードを `obsidian://gdsync-auth` へ転送するだけでシークレットは扱いません（PKCE + state 検証併用）。同じURLをプラグイン設定の「Redirect URI」にも入力してください。ウェブ型クライアントでデスクトップサインインも使いたい場合は `http://127.0.0.1:42813` も追加登録します。
</details>

### 2. プラグインのインストール

**コミュニティプラグイン（審査通過後）:** Obsidian のコミュニティプラグインで「GDSync」を検索。

**BRAT（ベータ）:** BRAT をインストール →「Add beta plugin」→ `https://github.com/surblue-git/gdsync`

**手動ビルド:**

```
npm install
npm run build
```

生成された `main.js`・`manifest.json`・`styles.css` を Vault の `.obsidian/plugins/gdsync/` にコピーして有効化します。

### 3. 接続

**デスクトップ（または最初にセットアップする端末）で:**

1. プラグイン設定にクライアントIDとシークレットを入力
2. 「Authenticate with Google」→ ブラウザで許可 → 完了（この間だけ `127.0.0.1:42813` でリダイレクトを受けます）
3. 「Test connection」で確認

**スマートフォンで:**

1. 接続済みデスクトップの設定 →「Connection code」→「Copy code」
2. コードをスマホに送り、プラグイン設定の「Enter code」に貼り付け。転送に使ったメッセージは**必ず削除**（コードはパスワード同等）

**同期する端末（通常はスマホ）で:**

1. 「Choose from list」で同期対象の Drive フォルダを選択（Drive の URL 貼り付けでも可）
2. 「Run full scan」→ `GDrive/` 配下にツリーが生成される

プラグインUIは Obsidian の表示言語設定に従い、**英語・日本語**に対応しています。

## 日常の使い方

- ファイルを開く → その場でダウンロードされ表示（2回目以降はキャッシュ、リモート更新があれば再取得）
- 編集 → 数秒後に自動アップロード
- リボンの同期アイコン / コマンド「Sync now」→ 保留分の送信 + リモート差分の取得
- アプリをフォアグラウンドに戻した時にも自動で差分同期

## 安全設計（重要）

- **空スタブで Drive を上書きしない**多層ガード（未取得ファイルの編集はアップロードされず警告）
- 削除は常に Drive の**ゴミ箱**へ（完全削除しない）。ローカル削除は Obsidian のゴミ箱設定に従う
- 競合時は両方の版を保持（ローカル版は `名前 (conflict 日時).md`）
- オフライン編集は保持され、オンライン復帰時に自動送信

## 制限事項

- Google ドキュメント/スプレッドシート等のネイティブ形式、ショートカットは同期対象外
- 設定の「最大ファイルサイズ」（既定20MB）を超えるファイルはダウンロードしない
- Drive 上の同名ファイルは ` (1)` 連番で区別
- `drive.file` ではなくフル `drive` スコープが必要（上記「必要要件」参照）

## リリース手順（開発者向け）

```
npm version patch   # manifest.json / versions.json も自動更新される
git push && git push --tags
```

タグを push すると GitHub Actions がビルドし、`main.js`・`manifest.json`・`styles.css` を添付したリリースを自動作成します。
